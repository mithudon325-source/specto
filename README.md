# Octave Spectrogram (VST3)

Scrolling spectrogram with a bright line at every octave (C). Audio passes through unchanged.

## Get the installer
1. Put this folder in a new GitHub repository (Add file > Upload files works).
2. Open the repo's **Actions** tab and wait for the build to finish (about 10-15 minutes).
3. Open the repo's **Releases** page (right side of the repo home) and download `OctaveSpectrogram-Setup.exe`.

## Install
1. Run `OctaveSpectrogram-Setup.exe` and click through. It installs to `C:\Program Files\Common Files\VST3`.
2. In FL Studio: Options > Manage plugins > Find plugins.
3. Add "Octave Spectrogram" to a mixer insert (or the Master).

Windows may show a blue "unknown publisher" screen because the installer is not code-signed. Click More info > Run anyway.

To uninstall: Windows Settings > Apps > Octave Spectrogram.
